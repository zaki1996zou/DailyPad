# DailyPad

DailyPad is a simple offline notes and tasks organizer for iPhone. Create notes with categories, pin favorites, manage tasks with due dates and priorities, and keep everything on your device — no account or internet required.

## Features

- **Notes** — Create, edit, delete, categorize, pin, favorite, and search notes
- **Tasks** — Today, Upcoming, and Completed sections with priorities and due dates
- **Home** — Quick actions, recent notes, and today's tasks
- **Settings** — Dark mode, privacy policy, support, app info
- **Offline** — All data stored locally with Hive

## Getting Started

```bash
flutter pub get
flutter run
```

## Requirements

- Flutter SDK ^3.11.0
- iOS 12+ / Xcode for iOS builds

## Privacy

DailyPad stores all data on your device. No login, cloud sync, notifications, or biometrics.
